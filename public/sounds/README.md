# Dossier des sons pour le Scanner de Billets

Déposez ici vos fichiers audio personnalisés :

- **`boarding-success.mp3`** : Son / message vocal joué lors de la validation d'un billet ("Embarquement validé, nous vous souhaitons un bon voyage").
- **`scan-error.mp3`** *(optionnel)* : Son joué en cas de billet invalide ou d'erreur.

Formats supportés : `.mp3`, `.wav`, `.m4a`, `.ogg`.
Le fichier `boarding-success.mp3` placé ici sera automatiquement lu par le scanner.
